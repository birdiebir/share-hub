# share-hub 設計規範

適用：share-hub 所有模板，包括首頁 `hub`、行程 `trip`，以及之後的文章、資源清單。新模板照這份做，舊模板改版時往這份靠。
基準：`templates\trip.html`（2026-11-02 晚的版本），數值取自 `<style>` 最後生效的值，也就是「可愛主題」「當代 App 質感」「行李頁」三段覆蓋之後的結果。
寫法：每條規則都可以檢查，後面的「因為」是理由。標了「（現況未符）」的是 trip.html 目前還沒做到的地方，改版時一起修。

---

## 1. 原則

1. **像裝好的 App，不像網頁**：底部分頁、上方標題列，一次只顯示一個畫面，不做長捲頁。因為作者偏好 App 式分頁。
2. **先給要用的資訊**：時間、價格、規定放在畫面和句子的最前面，情境描述放後面。因為對方多半是邊走邊看手機。
3. **有分類、有層次**：同類的東西收進同一張卡片，類別標題顯示進度。因為行李頁一長就容易亂。
4. **美術感靠字型、照片、留白**，不靠特效：手寫楷、襯線數字、滿版照片、紙條。因為單一字型讀起來太機械。
5. **完全離線、零外部依賴**：單一 HTML，不載第三方 script、字型、圖片，只用 CSS 變數上色。因為金鑰存在 localStorage，外部 script 讀得到；而且要離線可讀。

## 2. 設計 token

### 2.1 顏色（只用變數，模板裡不寫色碼）

| 變數 | 淺色 | 深色 | 用在哪 |
|---|---|---|---|
| `--bg` | `#fbf6ef` | `#0e141d` | 頁面底色 |
| `--surface` | `#ffffff` | `#142030` | 卡片 |
| `--surface-2` | `#fff0e6` | `#1a293b` | 卡片裡的次層底、進度條軌道 |
| `--text` | `#2b2233` | `#f4eff7` | 主文字；選中的分段用它當實心底 |
| `--muted` | `#6f6475` | `#aaa3b6` | 說明、日期、次要文字 |
| `--line` | `#f0e2d8` | `#24344a` | 分隔線、卡片框（通常再混 70～85% 透明） |
| `--accent` / `-ink` / `-soft` | `#0b7067` / `#fff` / `#dcf3ef` | `#5fd0c2` / `#062320` / `#143a3a` | 可以點的東西、連結、完成狀態 |
| `--coral` / `-ink` / `-soft` | `#e8625a` / `#b8433b` / `#ffe7e2` | `#ff8f80` / `#ffa597` / `#3a2228` | 重點數字、目前所在的分頁、項目標籤 |
| `--sun` / `--sun-soft` | `#ffc65c` / `#fff4d6` | `#ffd277` / `#33301f` | 暖色底、進度條漸層尾端 |
| `--rain-ink` / `--rain-soft` | `#2b679f` / `#e6f1fb` | `#8cc3f2` / `#172b40` | 雨天備案 |
| `--warn` / `--warn-soft` | `#9a4a07` / `#fdf0dc` | `#f2b25c` / `#3a2a12` | 3 天內到期、過期、離線條 |
| `--sos` | `#c43c3c` | `#ff7b74` | 應急卡、撥號鍵 |
| `--paper-note` / `-ink` / `-lbl` | `#fff1bf` / `#4b3c17` / `#9a7726` | `#39321d` / `#f2e6c2` / `#d9b866` | 小紙條 |
| `--sea` / `--land` / `--land-line` | `#d4eff2` / `#fdf3e3` / `#e8d6bd` | `#10283a` / `#1d2a32` / `#334553` | 地圖 |
| `--d` / `--d-soft` / `--d-ink` / `--d-on` | `.dc-1`～`.dc-4` 各一組（藍、紅、綠、紫） | 同左，深色另一組 | 每一天自己的顏色 |

規則：
- 一個顏色角色只做一件事：accent＝可以點，coral＝強調，warn＝時間緊，sos＝緊急。因為角色混用後，顏色就不能拿來傳達意思。
- 實心色塊上的字用對應的 `*-ink`／`--d-on`，不寫死 `#fff`。因為深色模式的實心色是淺色，白字會看不見。（11-02 已修：trip 深色模式的 `.pass-dir` 改深色字）
- 新增顏色要淺色、深色一起加，加在 `:root` 和 `@media (prefers-color-scheme: dark)`。因為只加一邊，另一個模式會壞。
- `<meta name="theme-color">` 的兩個值要等於兩個模式的 `--bg`。因為狀態列跟頁面不同色，一看就知道是網頁。（11-02 trip、hub 都已改成 `#fbf6ef`／`#0e141d`）
- 陰影和框線往所在的色相偏，淺色的 `--shadow` 用帶珊瑚色的 `rgb(184 67 59 / …)`。因為純黑陰影在暖色底上看起來髒（Vercel「Hue consistency」）。

### 2.2 圓角

| 級 | 值 | 用在哪 |
|---|---|---|
| 小 | 8px | 小標籤（截止日、票券狀態、去程回程） |
| 中 | 10～14px | 圖示方塊（34px 配 10～11px，40～44px 配 13～14px）、輸入框、分段按鈕、縮圖 |
| 大 | 16～18px | 卡片裡的次層（雨天、日期列）、路線圖、安裝卡 |
| 卡片 | 20～24px（`--radius`＝22px） | 卡片、照片卡、登機證、清單選單、橫滑卡 |
| 封面 | 26～30px | 分頁列 26、每天封面 28、總覽封面 30 |
| 膠囊 | 999px | 按鈕、時刻、狀態膠囊 |

- 裡面的圓角不大於外面，有內距時，裡面的圓角約等於外層減內距（分頁列 26、內距 5，分頁 21）。因為外大內小，曲線才會同心（Vercel「Nested radii」）。

### 2.3 陰影

| 級 | 值 | 用在哪 |
|---|---|---|
| 0 | 沒有陰影，只有 1px `--line` | 卡片裡的清單列、分隔 |
| 1 | `--shadow`：淺 `0 1px 2px rgb(184 67 59/.05), 0 10px 28px rgb(184 67 59/.08)`；深 `0 1px 2px rgb(0 0 0/.35), 0 10px 28px rgb(0 0 0/.3)` | 一般卡片 |
| 2 | `0 10px 30px rgb(0 0 0/.14)`、`0 12px 30px rgb(0 0 0/.12)` | 浮在內容上的：分頁列、倒數卡 |
| 3 | `0 16px 34px rgb(0 0 0/.14)`～`0 18px 40px rgb(60 30 20/.18)` | 封面照 |

- 陰影一定是兩層（近的小、遠的大）。因為單層看起來像貼紙，不像浮起來（Vercel「Layered shadows」）。
- 越大越浮的面，陰影越深；同一個畫面最多三級。因為層次靠對比，每樣都浮就沒有層次。

### 2.4 間距

基本級距：4、6、8、10、12、16、22、28px。不用這些以外的數字，除非是光學微調（±1～2px）。

- 頁面左右 16px，加上安全區：`max(16px, env(safe-area-inset-left/right))`。
- 頁面底部留 `132px + env(safe-area-inset-bottom)`，讓最後一張卡不被分頁列蓋住。
- 卡片內距 16px；照片卡文字區 12～14px；卡片之間 12px。
- 畫面第一個區塊離標題列 16px；區塊和區塊之間 22～28px。
- 清單列上下 12～13px，列之間 1px 分隔線。
- 因為：間距一致，才分得出「同一組」和「下一組」（Apple「Grouping & mapping」）。

### 2.5 字型三層

| 層 | 變數 | 字型與退路 | 用在哪 | 不要用在 |
|---|---|---|---|---|
| 手寫楷 | `--f-hand` | `TripHand`（霞鶩文楷 TC）→ Kaiti TC → STKaiti → BiauKai → DFKai-SB | 標題列、段落標題、卡片標題（地名、飯店、票名）、分類標題、小紙條 | 內文段落、說明、按鈕、標籤、表單 |
| 襯線數字 | `--f-num` | `TripNum`（DM Serif Display）→ Iowan Old Style → Palatino → Georgia | 倒數、進度數字、時刻、機場代碼、總金額、Day 編號 | 混在中文句子裡的數字 |
| 系統黑體 | （body） | system-ui → -apple-system → PingFang TC → Noto Sans TC → Microsoft JhengHei | 其他全部 | — |

- 手寫楷只用 `font-weight: 500`，加 `font-synthesis: none`。因為只嵌一個字重，瀏覽器硬加粗會糊掉。
- 襯線數字只用 400。因為 DM Serif Display 只有 Regular。
- 字型由 build 縮成只含用到的字。新模板裡用 JS 組出來的字（例如「第 N 天」），要確認 build 掃得到（模板本身或資料裡要出現）。因為沒掃到的字會退回系統字，同一行變兩種字型。
- 用手寫楷的標題加 `text-wrap: balance` 和 `word-spacing: -.12em`。因為楷體的空格看起來特別寬，長標題也容易剩一個字掉到下一行。
- 小紙條的標籤（「小提醒」那種）用系統黑體 12px、`letter-spacing: .14em`。因為手寫楷做成小字標籤會看不清楚。

### 2.6 字級表

| 角色 | 字型 | px | 行高 | 字重 |
|---|---|---|---|---|
| 封面標題 | 手寫 | clamp(40, 12vw, 58) | 1.08 | 500 |
| 每天封面標題 | 手寫 | clamp(28, 8vw, 36) | 1.2 | 500 |
| 標題列 | 手寫 | 25（窄版 21） | 1.2 | 500 |
| 段落標題 h2 | 手寫 | 23 | 1.3 | 500 |
| 卡片標題 | 手寫 | 18～23（票 18、想去的 19、每日卡 21、飯店 23） | 1.3～1.35 | 500 |
| 小紙條 | 手寫 | 18 | 1.65 | 500 |
| 項目標題 | 系統 | 17 | 1.42 | 700 |
| 導言 | 系統 | 17 | 1.75 | 400 |
| 清單標題 | 系統 | 16 | 1.45 | 700 |
| 內文 | 系統 | 16 | 1.65 | 400 |
| 項目說明 | 系統 | 15 | 1.7 | 400 |
| 說明（次要） | 系統 | 14 | 1.55～1.6 | 400，`--muted` |
| 標籤、膠囊 | 系統 | 12～13 | 1.6 | 600～700 |
| 分頁列文字 | 系統 | 12 | — | 600 |
| 照片署名 | 系統 | 10～11 | — | 400 |
| 大數字（倒數） | 襯線 | 46 | 1 | 400 |
| 中數字（代碼、總計、進度） | 襯線 | 30～42 | 1 | 400 |

- 字越大，行高越緊：標題 1.08～1.35、內文 1.65～1.75。因為大字行距太鬆會散，中文內文太緊會擠（漢字標準格式的文章行高預設 1.7）。
- 層次同時用字型、字級、字重、顏色四樣來拉開，不只靠放大。因為只放大字，畫面會很吵（Apple Typography）。
- 內文不小於 14px，輸入框不小於 16px。因為 iOS 遇到小於 16px 的輸入框會自動放大頁面。
- 並排比較的數字（金額、時刻表）加 `font-variant-numeric: tabular-nums`。因為等寬數字才對得齊。

## 3. 版面與元件

### 3.1 App 殼

**底部分頁列**：切換主畫面。
- 浮起的膠囊：左右各 12px、離底 `10px + safe-area`、圓角 26、內距 5、陰影第 2 級，底色是 `--surface` 混 92%＋`blur(14px)`。
- 最多 5 個分頁，每個是圖示加 12px 文字，高度至少 54px；選中的分頁用 `--coral-soft` 底、`--coral-ink` 字，並加 `aria-current="page"`。
- 打字時往下收起（`body.typing` → `translateY(160%)`）。因為手機鍵盤彈出後，分頁列會擋住輸入框。
- 分頁名稱寫內容（行程、預訂、行李），不寫「首頁」「其他」這類籠統的詞。因為名稱具體，點下去會看到什麼才猜得到（Apple「Direct, specific labels」）。

**標題列**：告訴對方現在在哪裡、怎麼回去。
- `position: sticky`，上方留 `safe-area-inset-top + 10px`，底色是 `--bg` 混 88%＋`blur(14px)`；下緣用 1px 陰影線，不用實線框。
- 標題用手寫 25px，太長就截斷加刪節號；有上一層時左邊放「‹ 返回」，點擊範圍至少 44px。
- 手機返回鍵要回上一個畫面（`history.pushState`／`popstate`）。因為 Android 使用者習慣用返回鍵。

**分段切換**：同一個分頁裡的子畫面（總覽／Day 1～N、機票／住宿／其他）。
- 一排膠囊，每顆的高度至少 44px、圓角 14、字 14px／650，第二行可以加 11px 小字（日期）。
- 選中的用 `--text` 實心底、`--bg` 字、第 2 級陰影；「今天」那顆沒選中時用 coral 色框和字。
- 用 `role="tablist"`／`role="tab"`，加 `aria-selected`。
- 超過 5 顆就改成可以橫滑。因為 384px 寬的手機放 6 顆以上，字會擠到看不清楚。

### 3.2 封面照

用途：每個主畫面（總覽、每一天、之後的文章）的第一眼。
- 總覽：比例 4:5，最小高度 380px，最大高度 66vh，圓角 30，陰影第 3 級；每天的封面：比例 16:12，圓角 28。
- 照片上要疊漸層遮罩（上方 .28、中間透明、下方 .78），文字放左下，字是白色加 `text-shadow`。因為不管照片多亮，都要讀得到標題。
- 署名放右下角，10px，`rgb(255 255 255/.85)`，一定要有（作者、授權、出處連結）。因為 CC 授權規定要標示，build 也會檢查。
- 沒有照片時改用 `--hero` 漸層或 `--d-soft` 漸層，字改回 `--text`、拿掉陰影。因為所有狀態都要設計到（Vercel「All states designed」）。
- 最大高度用 `svh`（11-02 已改 `66svh`，保留 `66vh` 當舊瀏覽器的退路）。因為手機的 vh 是網址列收起後的高度，封面會被切掉。
- 浮在封面下緣的卡（倒數）往上疊 40px，圓角 22、陰影第 2 級。

### 3.3 卡片

用途：一件事一張卡。
- 一般卡片：`--surface` 底、1px `--line`（混 80%）、圓角 22、`--shadow`、內距 16。
- 照片卡：照片在上（16:10，不加圓角，由卡片 `overflow: hidden` 裁切），文字區內距 12～14。
- 橫滑卡：寬 78%、最寬 320px、`scroll-snap-type: x mandatory`、`overscroll-behavior-x: contain`，右邊露出下一張的一部分。因為露出一角，對方才知道還可以往右滑。
- 可以點的卡片，整張都可以點，右邊加 `›` 箭頭，按下縮到 `scale(.98)`。因為只有一部分能點，對方會點空（Vercel「No dead zones」）。
- 小紙條（`tip-note`）：`--paper-note` 底、手寫 18px、旋轉 -1.2°、上方一條膠帶；一個畫面最多一張。因為多了就不特別了。

### 3.4 清單（標題：說明）

用途：要逐項掃過的東西（待辦、行李、規定）。
- 一列兩層：標題（系統 16px／700）、說明（14px／1.6，`--muted`）。資料寫成「標題：說明」，模板用第一個全形「：」拆開。
- 標題要短，看一眼就懂（現有資料大多 3～8 個字）；細節、條件、例外都放說明。
- 有截止日或負責人時，放在說明下面一排小標籤。
- 可以打勾的清單：圓形勾選框 24px，整列都是點擊範圍（`<label>` 包住）；打勾後標題加刪除線、說明和標籤變淡到 .6。
- 改清單文字前，先把 `key` 設成原文。因為打勾紀錄是用 key 存在對方手機裡的，文字一改就對不上。
- 資訊列（左邊名稱、右邊內容）用 `dl.info`：名稱欄 5.2em、14px／650、`--muted`。

### 3.5 分類卡（進度＋類別）

用途：清單超過一類時（行李、之後的資源清單）。
- 最上面一張進度卡：左邊文字、右邊襯線大字「已完成／總數」（34px、`--coral-ink`），下面 8px 進度條（coral→sun 漸層），再下面一行「最近要做的事」。
- 每一類一組：類別標題是 34px 圖示方塊（圓角 11）＋手寫 21px 類別名稱＋右邊「完成／總數」小膠囊（系統 13px／700）；全部完成時，小膠囊改成 `--accent-soft`。
- 類別圖示方塊輪流用 coral、accent、sun 三種底色。
- 類別的順序和圖示寫在資料裡（例如 `checklist_groups`），不寫死在模板。因為不同主題的類別不一樣。
- 一類至少 2 項；只有 1 項的併到相近的類別。因為一類只有一項，分類就沒有意義。

### 3.6 標籤

用途：狀態或屬性的小記號，不能點。
- 12～13px、600～700、soft 底加 ink 字；圓角是 999px（膠囊）或 8px（截止日、票券狀態）。
- 種類：重點（coral）、選擇性（`--surface-2`＋`--muted`）、截止日（accent；3 天內或過期改 warn）、負責人（`--surface-2`）、狀態膠囊（完成的加圖示）。
- 標籤一定有文字，不能只靠顏色表達意思（例如過期要寫「（過期）」）。因為色弱看不出來，而且深淺模式的顏色不一樣。

### 3.7 按鈕

| 種類 | 樣式 | 用在 |
|---|---|---|
| 主要 | `--accent` 底、`--accent-ink` 字、膠囊、高 44、左右 16～18、陰影 `0 4px 12px` 混 accent 25% | 導航、安裝、地圖 |
| 次要 | soft 底、ink 字、膠囊 | 卡片裡的連結（地圖、官網） |
| 緊急 | `--sos` 底、深色模式字改 `#1a0d0d` | 撥號 |
| 文字 | 無底、accent 字、600 | 返回 |
| 只有圖示 | 44×44，一定要加 `aria-label` | 關閉安裝卡 |

- 按鈕上寫動作的結果（「導航過去」「在 Google Maps 打開」），不寫「確定」「繼續」。因為看按鈕就該知道按下去會發生什麼。
- 外部連結後面加 `↗`。因為對方要知道會離開這個 App。
- 離開站內的導覽用 `<a>`，在頁面裡做事的用 `<button>`。因為 `<a>` 才能長按、在新分頁打開。
- 次要按鈕的高度也要 44px（11-02 已改成 44px）。

### 3.8 空狀態與載入

- 每種「沒有」都要有畫面：沒有內容、沒有網路、沒有金鑰、沒有照片。
- 空狀態寫兩句：缺了什麼、接下來可以做什麼（現有的例子：「需要分享連結」＋「請用對方傳給你的完整連結打開這一頁。」）。因為畫面不能是死路（Vercel「No dead ends」）。
- 空狀態用 `--surface-2` 底、`--muted` 字、圓角、內距 18；整頁的空狀態（gate）用 `100dvh` 置中，標題 18px。
- 載入中的骨架要跟最後的版面形狀一樣（標題寬 60%、副標 40%、內文滿版）。因為形狀不同，內容出來時版面會跳。
- 離線條：`--warn-soft` 底、`role="status"`，寫「沒有網路，顯示的是上次打開的版本」。

## 4. 手機手感（檢查清單）

摘自 mobile-native，後面標 trip.html 現況。

- [ ] viewport 加 `viewport-fit=cover, interactive-widget=resizes-content`，固定在上下的元素用 `env(safe-area-inset-*)` 留邊。（trip ✓、hub ✓）
- [ ] `html { -webkit-tap-highlight-color: transparent; -webkit-text-size-adjust: 100%; }`，每個能點的東西都要有自己的 `:active`。（✓）
- [ ] 控制項加 `touch-action: manipulation`。因為不加的話，點下去要等雙擊縮放的判斷。（✓）
- [ ] `user-select: none`＋`-webkit-touch-callout: none` 只加在控制項，內文（地址、電話、說明）要能選取複製。（✓）
- [ ] 輸入框字級至少 16px，並設對 `inputmode`（金額用 `decimal`）。不准用 `maximum-scale=1` 或 `user-scalable=no`。（✓）
- [ ] App 殼和整頁置中用 `100dvh`，封面用 `svh`，不用 `vh`。（封面未符）
- [ ] `:hover` 一律包在 `@media (hover: hover) and (pointer: fine)` 裡。因為手機點過以後 hover 會一直卡著。（trip ✓、hub ✓）
- [ ] 橫滑區塊用 `scroll-snap`，加 `overscroll-behavior-x: contain`。（✓）
- [ ] 整頁**保留**下拉重新整理，不在 `html` 加 `overscroll-behavior: none`。因為對方要靠重新整理拿到最新版（與 mobile-native 基準不同，見第 9 章）。
- [ ] `theme-color` 淺深各一個，等於 `--bg`。（trip ✓、hub ✓）
- [ ] 截圖用 384×854（常見 Android 手機）淺深各一套，每 1700px 分段截；最後一定要在真的手機上點過一輪。因為黏住的 hover、點擊延遲、鍵盤、安全區，在模擬器上都看不出來。

## 5. 互動與動態

- 按下的瞬間就要有回饋：`:active` 縮到 `scale(.94～.98)`（小按鈕 .94、卡片 .98、分段 .96），按下時的過渡時間是 100ms。因為放開才有反應會覺得卡（Apple「Respond on pointer-down」）。
- 時長：按壓 100ms；顏色、底色 200ms；畫面切換 220ms（淡入加上移 6px，`ease-out`）；區塊進場 300ms（`cubic-bezier(.16,1,.3,1)`）。超過 300ms 的只用在第一次載入。
- 彈跳曲線 `--bounce`（`cubic-bezier(.34,1.56,.64,1)`）只用在小東西：按鈕縮放、勾選框跳一下（280ms）。大面積的東西（卡片、畫面、封面）不彈。
- 只動 `transform` 和 `opacity`；`transition` 要列出屬性，不寫 `all`。因為動到寬高會讓整頁重排。（進度條目前動的是 `width`，數量少可以接受，新元件改用 `scaleX`）
- 動畫不能擋操作：切換到一半可以再點別的，不用等動畫跑完。
- 之後如果做拖拉（底部抽屜、滑動關閉）：手指移動和畫面 1:1、放手時接著手指的速度，彈簧用 damping 1.0、response 0.3～0.4 秒；每個手勢都要有可以用點的替代做法。
- `prefers-reduced-motion: reduce`：進場動畫和彈跳都拿掉，`transition: none`；進場動畫寫在 `no-preference` 裡面。（✓）
- 半透明的標題列、分頁列在 `prefers-reduced-transparency: reduce` 時改成實心、拿掉 blur（新增）。半透明的面不疊在另一層半透明上。因為疊兩層字就糊了。
- 新內容出現（離線、存好筆記）用 `role="status"` 或 `aria-live="polite"` 通知。

## 6. 文字

### 6.1 口吻

- 寫給對方本人：作者是「我」，對方是「你」，一起的事用「我們」。對象不是熟人時，人稱照對象調整。
- 口語、台灣用語，像傳訊息時會講的話；不肉麻、不撒嬌。
- 不用 emoji、不用行銷詞（絕美、必去、超值、打卡聖地、一次滿足）、不用「讓我們一起…」這類套話。
- 標題短而有畫面（「下班直奔車站，晚上到」），實用資訊放在句子前面（「一人約 NT$500，含…」）。
- 照實寫條件和不確定的地方（「要付費的話…」「我要決定要不要…」），不要為了順口把限定詞拿掉。
- 寫完先跑 `speak-human-tw`，再拿 `stop-slop` 檢查一遍。

### 6.2 排版（中文文案排版指北，加上現有資料的寫法）

- 中文和英文、中文和數字之間加半形空格：「搭 MRT」「3 天 2 夜」。
- 數字和單位之間加空格：「23 kg」「30 分鐘」；百分比、度數不加：「15%」「28°」；幣別符號直接接數字：「NT$1,100」。
- 全形標點前後不加空格：「iPhone，好開心」。（例如「（五）～ 1/3」的「～」後面不能多空格）
- 中文句子用全形標點（，。：；！？「」（））；數字一律半形；完整的英文句子或名稱裡用半形標點。
- 不重複用標點（不寫「！！」「？？」）；刪節號用「…」。
- 專有名詞照官方大小寫：iPhone、Google Maps、Wi-Fi。
- **現有寫法（跟外部來源不同時以這個為準）**：
  - 範圍用全形「～」，前後不加空格：「13:30～17:45」「30～35 分鐘」。
  - 時刻用半形冒號：「12:00」（數字半形）。
  - 「標題：說明」的冒號一定用全形「：」，即使前面是英文（「MRT：…」）。因為模板靠它拆成兩層。
  - 並列的代碼、名稱用全形「／」：「AB123／AB456」。
  - 日期寫「12/4（五）」，星期放全形括號。
  - 引號用「」，引號裡面再引用時用『』。

### 6.3 中文排版細節（取自漢字標準格式的概念）

- 中文不用斜體來強調，改用加粗或換顏色；真的需要在段落裡強調時，用著重號（`text-emphasis: filled circle; text-emphasis-position: under`），一段最多一處。因為漢字沒有斜體，瀏覽器硬斜會變形。
- 「另一種聲音」（小紙條、手寫標題）用楷體，跟漢字標準格式把 `<i>` 顯示成楷體是同一個想法。
- 標點不懸掛到行外。因為繁體中文的習慣是不懸掛。
- 中文段落不首行縮排，段落之間用間距隔開。因為在手機上，段距比縮排好認。

### 6.4 改寫後一定要查核

- 文字改寫完，派獨立的查核 agent 逐欄比對改寫前後：數字、名稱、規定都不能變。
- 最常錯的三種：括號裡的限定詞被拿掉（「平日不用預約」寫成「不用預約」）、多加了「只、才、一定」這類加重語氣的詞、「同一家的另一種方案」寫成「另一家」。
- 事實（營業時間、票價、電話、規定、加總）要對照官方來源，錯的改完才推送。

## 7. 無障礙

- 對比：內文、說明至少 4.5:1；24px 以上或 19px 粗體以上的字至少 3:1。目前實測：淺色 `--muted` 在 `--bg` 上是 5.2、在 `--surface-2` 上是 5.0；`--coral-ink` 在 `--coral-soft` 上是 4.55；深色都在 6 以上。
  - 11-02 已修：深色的 `.pass-dir` 改深色字；淺色的 `--paper-lbl` 改成 `#7a5c14`（約 5.5）。
- 點擊範圍至少 44×44px；看起來比較小的東西，用內距把點擊範圍撐大。
- 照片：`alt` 寫照片裡是什麼地方（取資料的 `photo.alt`）；純裝飾的圖示 SVG 加 `aria-hidden="true"`。
- 地圖 SVG 用 `role="img"`，`aria-label` 寫「幾個地點、編號對應下面的行程」。
- 只有圖示的按鈕加 `aria-label`；分頁加 `aria-current`；分段加 `role="tab"` 和 `aria-selected`。
- 焦點框：`:focus-visible` 2px `--accent` 外框、外推 2px；黏在上下的標題列和分頁列不能蓋住有焦點的元素（用 `scroll-margin`）。
- `<html lang="zh-Hant">`；標題用 h1～h3 照層級排，不跳級。
- 不能禁止縮放；能用原生元素（`button`、`a`、`label`、`input`）就不用 ARIA 模擬。
